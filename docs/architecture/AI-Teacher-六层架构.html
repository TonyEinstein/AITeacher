🔒 管理员职责分配示例
管理员（学校端）在后台为 Agent 打标签：
学科：小学数学 / 英语…
班级：三年级2班
可用工具：点名、提问、打分（不可调财务、不可看别班）
行为禁区：不评判外貌、不聊与课业无关话题、不给医疗/升学承诺
越权 → 立即拦截 + 记录 + 通知管理员
PRD v1.0 关键约束分别落在哪一层
PRD 约束 落在哪层 怎么落地
核心 IP 永不落地 L3 云端 + L6 Agent 提示词/Skill 规则/教学流程只存云端；教室端只装"加壳"客户端，启动需在线鉴权
断网降级 L1 教室端 课前下发当节课件包；断网只能按预热稿讲完，即兴互动降级，不能离线照常上课
多人并发 L2 多 Agent + L4 多路流 课堂 Agent 一班一科一个，辅导 Agent 一人一个实例并行；L4 同时收多路音视频流
数据归学校/云端存储 L6 云端 学生数据云端 PostgreSQL 存储、归学校所有；摄像头只传结构化事件，不传视频流上云
