AI Teacher 产品分层架构
桌面端（课堂/辅导实时工作端）+ Web 管理后台 · 模块关系示意
① 终端层
🖥 教室桌面端（主）
主摄像头 + 麦克风阵列 · 课堂授课与实时辅导 · AI Agent 常驻运行
⌚ 学生可穿戴设备
智能眼镜（看）/ 智能手表·耳机（听·说）· 一对一辅导随身采集
🌐 Web 管理后台
排课 · 花名册 · 人脸绑定 · 请假审批 · 评估报表（任意浏览器/手机）
▼
② IoT 设备网关层（你说的"物联网层"）
设备发现与配对
蓝牙 / USB / Wi-Fi 扫描，绑定到学生
音视频流接入
多路音频/视频统一接入、缓冲、降噪
设备状态管理
在线/离线、电量、占用、重连
▼
③ AI 能力层（LLM 走第三方 API，Key 由你在云后台配置，学校端碰不到）
🧠 LLM 大脑
授课/答疑/生成教案
🎙 语音 ASR/TTS
听懂学生 / 开口讲课
😊 人脸 / 行为识别
认人 · 表情 · 举手 · 开小差
📏 规则 / Skill 引擎
纪律、请假、提问策略、评分规则
▼
④ 业务 Agent 层（产品核心）
📚 课堂 Agent
定时上课 · 按教案讲 · 提问互动 · 点名考勤 · 维持纪律
🤝 辅导 Agent
穿戴设备随身听看 · 一对一答疑 · 观察学生状态
🗂 课程规划 Agent
上传电子版教材 → 拆大纲 → 排进度 → 生成每课教案
🧑‍🏫 学籍与考勤
花名册 · 人脸↔姓名绑定 · 迟到/旷课/请假状态 · 提问前过滤
📊 评估与报表
每课表现分 → 课堂报告 → 历史综合分析 → 图表看板
▼
⑤ 数据层
学生档案 + 人脸库
教材库 + 课程/教案
行为与考勤日志
历史评估与成绩
关键数据流（一次完整上课循环）
① 课程规划 Agent 从教材库生成本节教案与点名册 → ② 课堂 Agent 到点启动，通过 IoT 网关开主摄像头 → ③ 人脸识别把画面中的脸对到花名册，先查考勤状态（请假/迟到/旷课）再决定是否提问 → ④ 行为识别把"开小差/举手/回答"信号交给规则引擎打分 → ⑤ 课后自动生成本课表现分，写入历史评估 → ⑥ 评估与报表 Agent 结合历史数据，产出该生综合分析与图表。辅导流程复用 ②③④⑥，只是终端从教室主摄像头换成学生穿戴设备。
