为什么学校拿不到你的核心？
在学校端（可被拷走的） 在你的云（学校永远碰不到的）
界面壳、连接逻辑、显示控制 Agent 提示词、Skill 规则、教学流程
教室音视频采集与本地识别（只传结构化事件） LLM 调度策略、数字人参数下发
本校学生数据（归学校） 订阅鉴权、计费、多租户逻辑
即使学校破解了客户端，它拿到的只是个"遥控器"——没有大脑。真正的教学智能全在你的云上，断网或订阅到期，客户端就变成空壳。
⚠ 这个架构带来的一个必须接受的代价
之前说的"离线可用"现在要让步了——核心在你的云上，学校断网就无法实时上课和互动。 折中方案：课前把这节课的 PPT 和数字人讲稿预渲染缓存到学校客户端，断网时只能"放预录内容"（不能即兴点名、不能实时回答学生问题）。你接受这个 trade-off 吗？
