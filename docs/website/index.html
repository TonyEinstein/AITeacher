FAQ

常 见 问 题

断网了怎么办？

教室双链路兜底，主网络断自动切 4G/5G，无感知。

学生数据安全吗？

数据归学校所有，人脸和成绩加密存储，不外泄。

怎么部署？

学校装一个客户端（教室小盒子出厂预装），教室接投影和摄像头，网线连好即可。

多少钱？

按学校年订阅，费用按教室数核算（教室越多费用越高），加购模块单独计费；寒暑假可低成本开通辅导。具体报价请联系我们获取。

有问题找谁？

专属运维对接，可远程协助排查，重大故障提供应急预案。
