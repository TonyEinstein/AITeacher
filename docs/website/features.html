教育的四大难题

校

降本增效
02
家

家长辅导难、沟通少

家长工作繁忙无力辅导，对孩子课堂表现一无所知。AI Teacher 支持家长实时看课、接收课堂表现通知、查看综合评估报告，家校沟通零障碍。

家校透明
03
学

学生资源不均、个性化缺失

大班教学难以兼顾每个学生的节奏。AI Teacher 基于每个学生的历史数据生成个性化学习路径，错题自动归集、薄弱知识点针对性强化，因材施教。

因材施教

评

评估滞后、数据零散

传统评估依赖考试成绩，反馈周期长、维度单一。AI Teacher 每节课后即时生成多维度表现评分，结合作业、考试、课堂行为生成综合评估报告，数据驱动决策。

CORE FEATURES · 核心功能

六大核心能力

从课堂到课后，每一个环节都有 AI 深度参与

课堂教学

数字人教师
自动授课

基于教材电子版本，AI 自动生成教学大纲、PPT 课件与讲稿。数字人教师按稿授课，口型同步、手势自然，支持即兴提问与知识点拓展。

一个科目一个 Agent，也可一个 Agent 教所有科目，按学校需求灵活配置。课前自动预热缓存，断网亦可讲完本节课。

  • 教材自动解析 → 大纲生成 → PPT 制作 → 讲稿撰写
  • 2D/3D 数字人形象，可按学校定制（另收费）
  • 三种教学风格：严肃型 / 温柔型 / 幽默型
  • 即兴点名、课堂提问、案例插入

课堂互动

实时视觉感知
课堂全掌控

教室盒子配备双目摄像头与四麦阵列，AI 实时识别学生举手、讲话、走动、趴桌睡觉、迟到早退等行为，即时反馈给数字人教师。

学生举手即被识别并叫起回答；纪律问题自动警告并扣分；睡觉学生自动通知家长。旁听老师可实时纠正 AI 授课内容。

  • 人脸检测/识别：全班学生实时定位与身份确认
  • 行为识别：举手 / 讲话 / 走动 / 睡觉 / 迟到 / 早退
  • 四麦阵列噪声检测：课堂嘈杂度实时监控
  • 请假学生自动排除，不会被提问

课后作业

AI 自动批改
全题型覆盖

AI 按教案自动生成作业，管理员确认后下发至学生小程序。学生拍照提交，AI 自动批改客观题、主观题、计算题，按步骤给分并生成评语。

管理员可复核调整，错题自动归集到学生个人错题本，薄弱知识点针对性推送强化练习。

  • 客观题：选择/填空 100% 自动判分
  • 主观题：作文/论述 AI 初评 + 管理员复核
  • 计算题：识别解题步骤，按步骤给分
  • 错题自动归集 → 薄弱知识点 → 强化推送

个性辅导

一对一 AI 辅导
随时随地

学生佩戴智能眼镜与手表，AI 辅导 Agent 通过摄像头"看"到学生的作业与书本，通过麦克风"听"到学生的提问，实时语音回答。

辅导服务按学生开通，学校统一订购。支持 SOS 一键求助，辅导数据与课堂数据打通，生成完整学习画像。

  • 智能眼镜：第一视角采集，AI "看"题讲题
  • 智能手表：拾音 + 一键求助，轻便佩戴
  • ASR 语音识别 → LLM 思考 → TTS 语音回答
  • 辅导记录自动归档，与课堂评估联动
辅导对话流程

学情评估

全维度评估
数据驱动成长

每节课后 AI 自动从课堂参与、纪律表现、答题正确率、互动质量四个维度为每个学生打分。结合作业、考试、辅导数据生成综合评估报告。

支持班级/年级/校级/市级/省级/全国多级排名，成绩下滑自动预警。评估报告可一键分享至朋友圈，免登录可见。

  • 课后四维评分：参与度 / 纪律 / 答题 / 互动
  • 综合报告：课堂 + 作业 + 考试 + 辅导全维度
  • 多级排名：班级 / 年级 / 校级 / 市级 / 省级 / 全国
  • 自动预警：成绩下滑 / 连续缺课 / 纪律异常

家校互动

家长实时看课
家校零障碍

教室摄像头实时推流至云端，家长通过微信小程序即可观看孩子上课的实时画面，了解课堂内容与孩子状态。

家长留言经审核后可由 AI 在课堂上口头转达给学生（如"妈妈说今天加油"）。满意度问卷课后推送，家长反馈直接影响 AI 教学优化。

  • 实时直播：低延迟（< 3秒）课堂画面推送
  • 三端模式：学生 / 家长 / 教师，各见所需
  • 家长留言 → AI 课堂口头转达
  • 课后满意度问卷 → 数据驱动教学优化
