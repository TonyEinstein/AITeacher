# AI-Teacher 管理后台端到端全量核对总报告

> 核对日期：2026-09-22
> 核对范围：4 类管理员角色 × 21 个页面 × 数据加载 + 写操作落库验证
> 核对方法：API 直调（node http client）+ PostgreSQL 直查确认落库
> 服务状态：后端 :3000 / 前端 :5173 / PostgreSQL:5432 / Redis:6379 / SRS:1935+8080+1985（MinIO 镜像拉取中）

| 维度 | 结果 |

## 二、各角色核对结果摘要

### 2.1 super_admin（超级管理员）

- **覆盖**：21 页面，32 个 GET 接口 + 42 个写操作
- **写操作落库**：18/18 全部通过（学校 CRUD、年级/班级/学生/用户 CRUD、课表 CRUD、作业发布、考试创建+锁卷、教室创建、设备注册+分配、工单 CRUD+状态流转、订阅续订/启停、问卷创建、数字人创建、AI教师 CRUD+风格调整、题库 CRUD）
- **Bug（6 个）**：
  1. 🔴 `GET /users` 不传 schoolId 时仅返回 superadmin 自身（DB 有 16 用户但跨校查不到全量）
  2. 🟡 `DELETE /schedules/:id` 对有外键引用的记录报 500
  3. 🟡 `POST /exams/paper/:id/lock` 对不存在 ID 报 500（应 404）
  4. 🟡 数字人 avatar 无 DELETE 路由
  5. 🟡 `GET /surveys` 全量列表返回 404（路由缺失）
  6. 🟢 多个 GET 接口缺必填参数时返回 500 而非 400

详细报告：[核对报告_super_admin.md](核对报告_super_admin.md)

### 2.2 school_admin（学校管理员，GZ001_admin）

- **覆盖**：21 页面，15/21 页 GET 正常加载
- **写操作落库**：18 项全部通过（组织架构 CRUD 逐项验证、设备注册/分配、课表、作业发布、考试、请假审批、题库、AI教师、数字人、问卷、辅导订阅等）
- **数据隔离**：✅ 跨校查询全部 403；本校盒子仅返回 3 个（全库 15 个）
- **关键问题——6 个页面后端 403**：
  | 页面 | 后端接口 | 现象 |
  |------|---------|------|
  | /schools | GET /schools | 仅 super_admin 可访问 |
  | /device-monitor | GET /boxes/all | 仅 super_admin 可访问（建议改调 /boxes?schoolId=2） |
  | /leads | GET /leads | 仅 super_admin 可访问 |
  | /subscription | GET /subscriptions/school/:id | 仅 super_admin 可访问 |
  | /work-orders | GET /work-orders | 仅 super_admin 可访问 |
  | /health | GET /dashboard/health | 仅 super_admin 可访问 |
- **其他 Bug**：删除/更新不存在记录返回 500 而非 404（Prisma P2025 未捕获）

详细报告：[核对报告_school_admin.md](核对报告_school_admin.md)

### 2.3 grade_admin（年级管理员，GZ001_grade1）+ subject_admin（学科管理员，GZ001_math）

- **访问控制**：
  - 跨校越界：✅ 正确返回 403
  - 本校范围内 schoolOnly 接口：🔴 **后端未拦截**（/students、/boxes、/tutoring/*、/leaves/pending 用本校参数调用均 200 返回数据）
- **写操作落库**：9 组全部通过（subject_admin 题库 CRUD + Agent CRUD+风格、grade_admin 课表 CRUD）
- **数据加载**：教学主线 15 个页面全部 200 正常
- **Bug（5 个）**：
  1. 🔴 schoolOnly 接口后端未做角色校验（前端跳转拦截可被直接绕过）
  2. 🔴 leads/subscription/work-orders/health 页面 403 白屏
  3. 🟡 device-monitor 路由漏标 `schoolOnly: true`
  4. 🟢 subject_admin 写操作不校验学科归属（可创建其他学科题目/Agent）
  5. 🟢 subject_admin 可读任意年级数据（gradeId 不做归属校验）

详细报告：[核对报告_grade_subject_admin.md](核对报告_grade_subject_admin.md)
