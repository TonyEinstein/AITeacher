## 一、项目概述

**项目名称**：AI Teacher 智能教学系统
**技术栈**：NestJS + Vue3 + Electron + 微信原生 + PostgreSQL + Docker
**开发原则**：架构一步到位，3 个批次全部完成后一次性上线
**开发方式**：AI 辅助开发，所有任务并行推进

## 十五、常见坑与注意事项

### 树莓派 Electron 坑
1. **ARM 架构**：x86 上跑通了不代表树莓派上能跑，必须实际在树莓派上测
2. **性能**：Live2D 渲染 + 视频解码很吃 CPU，树莓派 5 才够用，树莓派 4 会卡
3. **摄像头驱动**：USB 摄像头要先确认在树莓派上能识别
4. **麦克风**：USB 麦克风阵列要确认 ALSA 驱动正常

### 微信小程序坑
1. **审核**：提前准备好审核材料，第一次审核可能要 3-7 天
2. **域名**：必须备案，且配置在小程序后台的服务器域名里
3. **WebSocket**：也要配置在后台，不然连不上
4. **直播**：小程序直播组件要单独申请权限

### Docker Windows 坑
1. **WSL2**：Docker Desktop 要开 WSL2 后端，不然很慢
2. **文件挂载**：Windows 挂载 Linux 容器性能差，数据卷要放 WSL 里
3. **端口冲突**：先确认本地端口没被占用

### 其他坑
1. **LLM API 限流**：调用频率太高会被限流，要做队列和重试
2. **人脸数据隐私**：学生人脸数据不能随便存，要加密
3. **时间同步**：树莓派和服务器时间要同步，不然 token 校验会出问题

## 十七、风险与注意事项

| 风险 | 影响 | 应对措施 |
|---|---|---|
