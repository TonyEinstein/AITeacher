## 二、技术方案（正式工程）

### 2.1 技术选型

| 项 | 选型 | 理由 |
|---|---|---|
| 框架 | **Vue 3 + TypeScript** | 与 admin-web 统一技术栈，团队零学习成本，组件模式可复用 |
| 构建 | **Vite 8** | 与 admin-web 一致；构建快 |
| 路由 | **vue-router**（多页路由） | 官网按 PRD 导航拆独立页面，利于 SEO 与内容扩展 |
| 预渲染 | **vite-ssg / prerender（构建期生成静态 HTML）** | 官网是营销站，SEO 关键（学校搜"AI老师""智能教学"要能找到）；构建产物为纯静态站，托管成本低、加载快 |
| 状态管理 | 不需要 Pinia（官网无复杂共享状态），表单直接用 fetch | 精简 |
| UI | 沿用现有水墨风设计（手写 CSS + 内联 SVG + Canvas 背景），不引第三方 UI 库 | 保持设计一致性，零额外依赖 |
| 图标 | 内联 SVG | 现状延续 |

> 备选：Nuxt 3（内置 SSG/SSR，SEO 能力更强），但引入新框架、学习成本更高。**建议先用 Vue3+Vite+预渲染**，若后续 SEO 数据不理想再升级。

### 2.5 用户新约束落实

1. **价格不公开**
   - FAQ 删除"多少钱"条目，替换为"**如何合作**：按学校年订阅、按教室数核算，具体方案与报价请联系我们获取"（只讲模式、不讲价格）。
   - 全站所有 CTA 统一指向"预约演示/联系我们"留资，不出现任何价格数字。
   - 商务流程保持 PRD §5.1：谈好价格后，运营在管理后台按学校配置"开通多久、多少钱、哪些功能模块"，**价格灵活调整不依赖官网**。
   - 标注：PRD §5.2 FAQ 清单中的"多少钱"一项需同步修订（记录决策变更）。

2. **ICP 备案位预留设置功能**
   - 官网页脚备案号由 `site-config.icpNo` 动态渲染：**配置了才显示**，未配置显示"ICP 备案号（备案后填写）"占位或直接隐藏（建议：未配置时隐藏整行，避免暴露未备案状态）。
   - 管理后台"官网设置"页可随时填写/修改备案号，无需改代码重新发版。
   - 隐私政策/用户协议先做独立占位页，内容待法务确认。
