# AI Teacher 部署运维手册

> 适用范围：AI Teacher 系统的云端部署、教室盒子部署、小程序发布、监控与备份。
> 采购原则：**能本地自实现的优先自实现；必须采购的云服务全部使用腾讯云（与微信生态结合最好），不使用阿里云。**

---

## 一、整体部署拓扑

```
┌─────────────────────────────── 腾讯云（中心云端）──────────────────────────────┐
│                                                                                │
│  CVM 云服务器（或轻量应用服务器）                                                │
│  ┌──────────────────────────────────────────────────────────────┐            │
│  │ Nginx（80/443）→ uni-app H5 静态托管（mobile-web） + /api 反代 + /ws WebSocket │            │
│  │ Docker Compose:                                              │            │
│  │   backend (NestJS:3000)                                     │            │
│  │   PostgreSQL16 / Redis7 / MinIO(试点) / SRS(直播)            │            │
│  └──────────────────────────────────────────────────────────────┘            │
│         │                │                  │                    │           │
│   TencentDB for PG   TencentDB for Redis   COS 对象存储      云直播 CSS/CDN      │
│     （正式商用）         （正式商用）        （正式商用替换MinIO） （正式商用）      │
└────────────────────────────────────────────────────────────────────────────────┘
            ▲                    ▲                       ▲
            │ HTTPS/WSS          │ HTTPS/WSS             │ RTMP/FLV
   ┌────────┴────────┐   ┌───────┴────────┐      ┌────────┴─────────┐
   │ 管理后台（浏览器）│   │ 微信小程序       │      │ 教室盒子（树莓派5）│
   │ 公司/学校管理员  │   │ 学生/家长/教师   │      │ 双目摄像头+4麦+4G │
   └─────────────────┘   └────────────────┘      └───────────────────┘

```

**核心 IP 保护原则**：教学 Skill、流程编排、Prompt 工程等核心资产只存在于云端后端；教室盒子、小程序、管理端都只是调用方，断网不可用（启动必须联网鉴权；课中断网可讲完已预热内容作为兜底）。

## 二、云端部署（腾讯云）

### 2.1 需要采购/开通的腾讯云资源

| 资源 | 用途 | 试点期建议 | 正式商用建议 |
|---|---|---|---|
| 域名 + ICP 备案 | 官网、API、管理后台 | 1 个主域名 | 同左 |
| SSL 证书 | HTTPS/WSS（小程序强制） | 腾讯云免费 DV 证书 | 同左 |
| 云服务器 CVM | 跑后端 + 编排服务 | 4核8G，带宽 10Mbps，系统盘 100G SSD | 8核16G 起 + 按量扩容 |
| TencentDB for PostgreSQL | 业务数据库 | 可用 Docker 自托管 PostgreSQL | 高可用版 PostgreSQL 16 |
| TencentDB for Redis | 缓存/队列/会话 | 可用 Docker 自托管 Redis | 标准架构 1G 起 |
| 对象存储 COS | 教材、作业照片、录像、快照 | 可用 MinIO 自托管 | COS 标准存储 + 低频归档 |
| 云直播 CSS | 课堂直播给家长（低延迟） | 可用 SRS 自托管 | 腾讯云直播（快直播/标准直播） |
| CDN | 静态资源、直播分发加速 | 试点可不用 | 全站 CDN |
| 短信 SMS | 登录验证码/通知（可选） | 按需 | 套餐包 |
| 云监控 + 告警 | 服务器/应用监控 | 免费基础版 | 自定义告警 |

> 带宽是本项目最关键的成本项：每间教室一路视频上传（约 2~4 Mbps），家长观看走 CDN 分发。试点学校（几十间教室）10~50Mbps 上行足够；规模化后课堂直播建议直接走腾讯云直播 + CDN，源站只做信令和业务数据。

### 2.2 一键部署（Docker Compose，试点/自托管）

```bash
# 1. 克隆代码到服务器
# 2. 配置环境变量
cd infra/docker
cp .env.prod.example .env.prod
vi .env.prod   # 填写数据库密码、JWT密钥、模型API Key

# 3. 启动全部服务
docker compose -f docker-compose.prod.yml --env-file .env.prod up -d --build

# 4. 查看状态
docker compose -f docker-compose.prod.yml ps
docker logs -f ait-backend
```

服务端口：
- 管理后台：`http://服务器IP/`（Nginx，80）
- API：`http://服务器IP/api/v1`
- WebSocket：`wss://服务器IP/ws`（教室）、`wss://服务器IP/wearable`（穿戴设备）
- MinIO 控制台：`9001`（仅绑定 127.0.0.1，生产不对外）

### 2.3 Nginx / HTTPS（生产）

- 用 Nginx 容器或主机 Nginx 终止 TLS，证书放 `/etc/nginx/cert/`。
- 小程序合法域名必须是 **HTTPS + 已备案域名**，在小程序后台配置 request、socket、uploadFile、downloadFile 合法域名。
- WebSocket 反代必须设置 `Upgrade`/`Connection` 头（见 apps/mobile/nginx.conf）。

### 2.4 大模型 API 配置

在后端环境变量配置至少一家（可多家做故障切换）：
- `DEEPSEEK_API_KEY`
- `DOUBAO_API_KEY`（豆包/火山方舟）
- `GLM_API_KEY`（智谱）
- （可选）OpenAI 兼容的 GPT 接口

无 Key 时后端 LLM 服务进入 mock 模式，仅用于开发联调，不可用于生产。

### 2.5 数据库迁移与种子

- 容器启动自动执行 `prisma migrate deploy`。
- 初始化超级管理员：执行种子 `npx prisma db seed`（生产请修改默认密码）。

## 三、教室盒子部署（树莓派 5）

### 3.1 硬件清单（每间教室）

| 设备 | 型号建议 | 数量 |
|---|---|---|
| 主控盒子 | 树莓派 5（8GB）+ 外壳 + 散热 + 64GB TF 卡 | 1 |
| 摄像头 | 双目 USB 摄像头（广角，覆盖全班） | 1 |
| 麦克风 | 4 麦阵列 USB（拾音 + 噪声检测） | 1 |
| 4G 备用链路 | 移远 EC20 4G 模块（USB） | 1 |
| 求助按键 | USB 自定义按键（可选） | 1 |
| 显示 | 教室现有投影仪/显示屏（HDMI） | 1 |
| 网络 | 有线网口（主链路，接楼层交换机/路由器） | 1 |

网络拓扑：教室盒子 → 楼层/年级交换机（有线主链路）→ 中心服务器；4G 模块作为备用链路自动切换。

### 3.2 首次部署（方案一：预装镜像深度集成）

1. 烧录 Raspberry Pi OS 64 位到 TF 卡。
2. 放入代码，运行：
   ```bash
   bash infra/pi/pi-first-setup.sh
   ```
   脚本完成：系统依赖、Python venv、视觉服务依赖、Electron 运行环境、systemd 服务注册、双链路配置、序列号写入。
3. 在管理后台「设备管理」注册盒子序列号并分配教室。
4. 开机自动进入全屏授课界面（Kiosk），视觉服务随系统启动。

### 3.3 OTA 升级

- 后端通过环境变量发布新版本：`OTA_VERSION`、`OTA_PACKAGE_URL`（升级包放 COS）、`OTA_CHECKSUM`（SHA256）。
- 盒子定时（或手动）执行：
  ```bash
  sudo bash /opt/ait-teacher/infra/pi/ota-update.sh https://你的域名
  ```
- 升级流程：查版本 → 下载 → SHA256 校验 → 备份 → 部署 → 重启 → 健康检查 → **失败自动回滚**。
- 升级结果通过 `POST /boxes/ota/report` 回报，管理端可看每台盒子的固件版本。

### 3.4 双链路兜底

- 主：有线 eth0（路由 metric 100）。
- 备：移远 EC20 4G（usb0，metric 更高）。
- vision-service 的 `network/monitor.py` 检测主链路不通时自动切到 4G，并在界面显示链路状态；恢复后切回。

## 四、穿戴设备（眼镜/手表）对接

- 智能眼镜：Rokid Glass 3（Android 平台，官方 SDK），设备端 App 采集第一视角音视频，经 `/wearable` 网关接入。
- 智能手表：W377E（紫光展锐平台），麦克风拾音 + 侧边 SOS 按键，经厂商 SDK 接入。
- 设备握手：Socket.IO 连 `/wearable`，发 `register { serialNumber }`；语音用 `voice_text`，求助用 `sos`，心跳 `ping`。
- 具体型号、SDK 文档链接、采购渠道见《硬件采购选型与SDK对接文档.md》。
- 实际厂商 SDK 适配在设备端 Android App 中完成（由固件厂商提供 Demo 改造），后端协议保持稳定。

## 五、微信小程序发布

1. 在微信公众平台注册小程序（企业主体）。
2. 配置服务器合法域名（HTTPS/WSS、upload/download 域名）。
3. 用微信开发者工具打开 `apps/mobile` 的 mp-weixin 构建产物（`npm run build:mp-weixin`），AppID 填入 `project.config.json`。
4. 联调通过后提交审核、发布。
5. 分享朋友圈：使用小程序「分享到朋友圈」能力（单页模式），分享页支持免登录查看评估快照。

## 六、监控、备份与安全

### 6.1 监控
- 主机/容器：腾讯云监控或 Prometheus + Grafana（CPU、内存、磁盘、网络）。
- 应用：后端暴露健康检查 `/api/v1/health`；盒子在线率、WebSocket 连接数、LLM 调用量/Token、直播流状态做业务看板。
- 告警：盒子大面积离线、LLM 调用失败率、磁盘 >85%、数据库连接异常 → 短信/企业微信通知。

### 6.2 备份
- PostgreSQL：每日逻辑备份（pg_dump）存 COS，保留 30 天；每周做一次恢复演练。
- 对象存储：COS 开启版本控制 + 跨地域复制（重要录像/作业）。
- 备份脚本建议加入 crontab：
  ```bash
  0 2 * * * docker exec ait-postgres pg_dump -U ait_prod ai_teacher | gzip > /backup/ai_teacher_$(date +\%F).sql.gz
  ```

### 6.3 安全
- 所有服务端口默认只绑定 127.0.0.1，对外仅暴露 80/443（Nginx）和直播端口。
- 数据库、Redis、MinIO 设置强密码，不使用默认密码。
- JWT 密钥、模型 API Key、腾讯云 SecretKey 只放环境变量/密钥管理，不入库不入 Git。
- 教室盒子、小程序、管理端与云端全程 HTTPS/WSS 加密。
- 学生人脸等生物特征数据属于敏感个人信息，需在学校采购合同与隐私政策中明确授权，数据加密存储，按合规要求设定留存期限。
